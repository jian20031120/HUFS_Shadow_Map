# HUFS 그늘길

한국외국어대학교 글로벌캠퍼스에서 **현재 위치부터 선택한 학교 건물까지 그늘을 우선하는 경로**를 보여주는 웹 데모입니다.
첫 화면은 지도, 현재 위치 버튼, 도착 건물 검색, 시간 선택으로 구성합니다. 건물 높이 분석표와 API 설정은 공개 화면에 표시하지 않습니다.
사용자가 제공한 연못 사진을 공통 배경으로 유지합니다.

## 실행

현재 PC의 주소: http://127.0.0.1:8501

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe start_web.py
```

설치 후에는 마지막 명령만 실행하면 됩니다. 실행기는 기존 서버가 정상이면 재사용하며,
필요하면 서버를 시작하고 기본 브라우저에서 사이트를 엽니다.
서버만 실행하려면 `start_web.py --no-browser`를 사용합니다.
PowerShell 실행 정책 때문에 `.ps1` 파일이 차단되는 PC에서도 Python 실행기를 사용할 수 있습니다.

TMAP 앱 키는 프로젝트 루트의 `.env`에 넣습니다. 실제 `.env`는 Git에서 제외합니다.

```dotenv
TMAP_APP_KEY=발급받은_App_Key
```

환경변수가 있으면 `.env`보다 우선합니다. `.env.example`에는 빈 설정 예시가 있습니다.
TMAP 지도 API 권한과 사용 도메인을 발급 서비스에서 설정합니다. 아이디·비밀번호는 앱에 입력하지 않습니다.
키가 없으면 OpenStreetMap 지도로 실행합니다. TMAP 지도 오류 시 지도 안의 `기본 지도로 보기`로 전환할 수 있습니다.
강제로 기본 지도를 열려면 http://127.0.0.1:8501/?map=osm 을 사용합니다.

## 사용 흐름과 범위

1. 사이트를 열면 캠퍼스 지도와 선택한 시각의 예상 그늘이 보입니다.
2. `내 위치로 찾기`를 눌렀을 때 브라우저가 위치 사용 동의를 요청합니다. 허용은 사용자가 직접 선택합니다.
3. 출발은 현재 위치로 고정됩니다. `도착 · 학교 건물`에서 건물 이름을 검색해 선택하면 그 건물까지 경로를 계산합니다.
4. 정확한 현재 위치가 캠퍼스 안일 때 경로를 제공합니다. 걸어서 위치가 바뀌면 `위치 갱신`을 누릅니다.
5. 건물이나 시간을 바꾸면 경로를 다시 계산합니다. 위치 지우기를 누르면 받은 좌표와 개인 경로를 제거합니다.

사이트 접속과 지도 미리보기는 외부에서도 가능합니다. 현재 위치 기반 추천은 캠퍼스 안에서만 제공합니다.
캠퍼스 밖, 권한 거부, 위치 실패, 5분이 지난 좌표에서는 건물 검색과 지도 미리보기를 제공하고 경로 계산을 보류합니다.
출발지를 임의의 캠퍼스 위치로 바꾸지 않습니다.
위치 정확도가 100m보다 낮거나 오차 반경이 캠퍼스 경계와 겹치면 위치 갱신을 안내합니다.
이 범위 판정은 기능의 데이터 범위를 제한하며 사용자 인증이나 물리적 접근 통제 기능은 아닙니다.

실제 좌표는 현재 Streamlit 세션에서만 사용합니다. 파일·URL·로그에 기록하지 않고 공유 계산 캐시에 넣지 않습니다.
브라우저 Geolocation API는 HTTPS 또는 localhost/127.0.0.1 같은 신뢰 가능한 로컬 환경이 필요합니다.
휴대폰에서 PC의 HTTP 사설 IP로 접속하는 방식은 위치 기능이 제한될 수 있어, 실제 교내 휴대폰 시연에는 HTTPS 배포가 필요합니다.

기본 시간은 현재 한국 시각입니다. 밤이나 태양 고도 3° 미만에서는 태양 그림자를 표시하지 않습니다.
밤에 시연하려면 시간 메뉴에서 오전 9시·정오 12시·오후 3시를 선택합니다.

## 구현 선택

이번 데모는 사용자의 요청에 따라 **보행로 선형에 제한되지 않는 목적지 건물까지의 그늘 우선 안내**를 구현합니다.
캠퍼스 경계 안에서 확보한 건물 도형 84개를 피하며, 나머지 공간을 이동 가능하다고 가정합니다.
실제 통행 가능 여부, 경사·장벽·출입 제한·물 영역은 이번 시연에서 확인하지 않습니다.
지도에는 이 가정을 `통행 미검증`으로 표시합니다.

격자 모델 안에서 햇빛에 노출되는 거리를 우선 줄이고, 노출 거리가 같은 후보에서는 이동 거리가 짧은 경로를 탐색합니다.
기본 격자는 3m이며 캠퍼스 전체 계산량에 맞춰 간격을 조정합니다. 연속 지면 전체의 전역 최적 경로를 보장하는 것은 아닙니다.
검색 범위는 캠퍼스 전체이며, 기존 가까운 그늘 추천의 250m 제한을 적용하지 않습니다.
녹색 면은 예상 그늘, 녹색 선은 안내선 중 그늘 구간, 주황색 선은 햇빛 구간입니다.
그늘이 연결되지 않으면 햇빛 구간이 포함될 수 있으며, 100% 그늘 경로를 보장하지 않습니다.
이미 그늘 안에서 출발해도 선택한 건물까지 경로를 계속 계산합니다. 연결할 수 없으면 경로를 만들어내지 않습니다.
도착 건물은 파란 윤곽으로 표시하고, 도착 표시는 건물 바깥의 계산된 접근 지점입니다. 실제 출입구로 검증한 위치가 아닙니다.
캠퍼스 경계는 회색 점선입니다. 턴 안내는 제공하지 않으며, 위치가 바뀌면 `위치 갱신`으로 다시 계산합니다.

OSM 독립 보행로 자료는 3개, 약 470m만 있어 전체 그늘 안내를 제한하기에 부족합니다.
기존 보행로와 그늘 교차 계산은 연구·회귀 검증용으로 보존하며 공개 안내선은 이 자료를 경로 제약으로 사용하지 않습니다.

## 높이와 계산

원본 GIS 75개와 GIS에 없는 OSM 윤곽 9개, 총 84개 도형을 보존합니다.
등록 높이 6개, 층수 추정 5개, GBA 윤곽 추정 10개, GBA 3m 격자 추정 53개로 총 74개를 계산에 사용합니다.
미확보 10개는 가정 높이를 넣지 않고 그림자 발생원에서 제외합니다. 확보된 윤곽은 안내선이 건물 내부를 통과하지 않도록 피합니다.
검토 기록은 `data/height_research_audit.json`, 미확보 위치는 `data/unresolved_heights.csv`와 GeoJSON에 있습니다.

위성 추정값은 실측값이 아닙니다. 격자 적용 53개 중 23개는 작은 도형·혼합 픽셀 때문에 신뢰도가 매우 낮습니다.
등록 높이와 GBA 윤곽 높이를 비교할 수 있는 표본은 1개뿐이며 차이는 약 2.66m입니다.
캠퍼스 전체 높이와 현재 그늘 정확도를 실측 검증한 결과는 아닙니다.
공개 지도는 평지 건물·입력된 나무의 근사 그림자를 사용합니다. 지형 경사, 구름, 계절별 수관 투과는 반영하지 않습니다.

## 개발 및 재현

`app.py`는 `map_app.py`의 공개 지도 화면을 실행합니다.
`campus_scene.py`는 오프라인 건물·높이·보행로 모델과 시각별 그늘을 계산하고,
`browser_location.py`와 `components/location_controls.*`는 위치 동의와 시간 조작을 담당합니다.
`campus_access.py`가 위치 정확도와 캠퍼스 범위를 판정합니다.
`shade_guidance.py`는 보행로 제약 없이 건물을 피하는 목적지 경로를 계산합니다.
`destination_catalog.py`는 로컬 건물 자료의 이름과 도형을 연결해 검색 가능한 목적지 목록을 만듭니다.
이전의 상세 편집 화면 사본은 Git에서 제외되는 `backups/app.before_map_only_20261025.py`에 보존했습니다.

```powershell
.\.venv\Scripts\python.exe -m unittest
```

테스트는 위도·경도 검증, 권한 거부·시간 초과·삭제 후 콜백, 교내·교외·경계 판정,
실제 보행로와 그늘 교차, 미확보 도형 제외, 낮·밤·오전·오후 변화와 공개 화면 구성을 확인합니다.
실제 브라우저 권한 허용과 현장 GPS 정확도는 사용자 기기에서 확인해야 합니다.

외부 자료 재수집은 명시적인 명령으로만 실행합니다. 앱 실행 중 자동 대용량 다운로드는 없습니다.

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-gba.txt
.\.venv\Scripts\python.exe fetch_gba.py
.\.venv\Scripts\python.exe fetch_gba_height.py
.\.venv\Scripts\python.exe gba_buildings.py
.\.venv\Scripts\python.exe fetch_walkways.py --refresh
```
